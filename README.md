## Frameworks

| Name | Description | Stars | Language |
|------|-------------|-------|----------|
| [hermes-agent](https://github.com/NousResearch/hermes-agent) | Open-source AI agent with tool calling, MCP, and multi-platform support | ⭐ 16k+ | Python |
| [LangChain](https://github.com/langchain-ai/langchain) | Build context-aware reasoning applications | ⭐ 95k+ | Python |
| [AutoGen](https://github.com/microsoft/autogen) | Multi-agent conversation framework | ⭐ 35k+ | Python |
| [CrewAI](https://github.com/crewAIInc/crewAI) | Framework for orchestrating role-playing AI agents | ⭐ 25k+ | Python |
| [OpenAI Agents SDK](https://github.com/openai/openai-agents-python) | Lightweight framework for building multi-agent systems | ⭐ 15k+ | Python |
| [Phidata](https://github.com/phidatahq/phidata) | Build AI Agents with memory, knowledge, and tools | ⭐ 18k+ | Python |
| [smolagents](https://github.com/huggingface/smolagents) | Barebones library for agents that think in code | ⭐ 12k+ | Python |
